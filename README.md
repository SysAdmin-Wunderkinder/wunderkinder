# WunderKinder e.V. – einfache Startseite

Diese Website ist eine sehr einfache, statische Homepage für den gemeinnützigen Verein "WunderKinder e.V.".

## Inhalte

- Startseite mit Vereinsvorstellung
- Übersichten zu Zielen, Aktivitäten und Hilfsangeboten
- Kontaktbereich mit sozialen Medien
- Impressum und Datenschutzerklärung für Deutschland

## GitHub Pages

1. GitHub-Repository erstellen
2. Diese Dateien hochladen
3. In den Repository-Einstellungen unter "Pages" den Branch `main` auswählen
4. Die Seite ist dann per GitHub Pages erreichbar

## Wichtiger Hinweis

Die im Beispiel verwendeten Adressen, E-Mail-Adressen, Vereinsdaten und Namen sind Platzhalter. Vor dem offiziellen Livegang müssen diese mit den tatsächlichen Angaben des Vereins ersetzt werden.

## Lokale Vorschau

```bash
python -m http.server 8000
```

Danach im Browser auf `http://localhost:8000` gehen.
